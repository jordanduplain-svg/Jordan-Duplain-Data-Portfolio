# Data Analyst Portfolio – Power BI, Python & Machine Learning

Bienvenue sur mon portfolio de projets data.  
Ce dépôt regroupe mes travaux pratique autour de l’analyse de données, de la visualisation Power BI, du nettoyage avec Pandas et de petites expériences en machine learning.

## À propos de moi

Je suis un **data analyst orienté Power BI** avec un goût pour la transformation de données brutes en tableaux de bord clairs et utiles.  
Je monte progressivement mes compétences en Python (Pandas, scikit-learn), SQL et machine learning, tout en restant centré sur la compréhension des besoins métiers/Business et la mise en place de dashboards lisibles.

## Ce que vous trouverez ici

- Analyse de données réelles (ex : données médicales, business, logistique, etc.).  
- Dashboards Power BI et visualisations avancées.  
- Nettoyage et préparation de données avec Pandas.  
- Petits projets de machine learning (prévision, classification, etc.).  

## Structure du dépôt

- `/aicha_medecine` : analyse de données de thèse médicale (nettoyage avec Pandas, visualisations et courbes).  
- `/pandas_cleaning` : exemples de nettoyage / transformation de données.  

## Pourquoi ce portfolio ?

Ce portfolio vise à :
- montrer mes compétences concrètes (pas seulement le CV),  
- illustrer mon processus de travail : données brutes → nettoyage → analyse → visualisation,  
- montrer ma capacité à apprendre et à expérimenter (Python, ML, automates, etc.).
